## Android 接入

按 [Android 官方自适应图标说明](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive) 分开提供背景、前景和主题单色层，图层均为 108dp。前景使用真正透明的 PNG，不预先绘制桌面外层遮罩。圆形、圆角方形、方圆形等外形由桌面决定；移除素材圆框不意味着强制桌面使用方形。

弹幕窗主体控制在中央 66dp 安全区内。人物保持近景头像比例，只把脸部、头饰和主要蝴蝶结放在安全区，原有长发及肩部属于可由遮罩裁切的外延内容；不再为保护整个半身而把人物缩成小贴纸。关键区域坐标见 `export_frameless_maids.py`，检查结果分别记录关键区域和装饰外沿的裁切量，不能把外沿正常裁切当作关键内容丢失。

保留 `icon_3d` 等设置键、Activity alias 和资源入口。原「3D立体」显示名为「弹幕播放窗」，已有选择无需迁移。女仆系列与弹幕播放窗共用图标页顶部的“跟随系统／浅色／深色”入口；弹幕窗的固定浅深色拥有独立桌面 alias、图标资源、预览与启动页入口，关闭启动图标时也沿用所选外观。普通、圆形后备图、显式浅深色和跟随系统的资源均同步导出；去重别名及 SHA 清单一起更新。播放通知小图标使用相应单色资源。人物头像的启动页、设置预览与默认商店图同步引用或导出当前造型。

```sh
PYTHONDONTWRITEBYTECODE=1 python artwork/app-icon/export_play_window.py
```

## BiliPai 标志矢量与预设配色

- `bilipai-mark.svg`：从既有蓝白标志轮廓提取的路径源文件，保留电视和文字造型。
- `ic_bilipai_mark*.xml`：蓝白、紫、绿、墨色与主题单色层使用同一套路径。白色版前景与动态色启动页也使用矢量资源；`mipmap-anydpi` 入口优先于保留的历史密度 PNG。
- 图标页直接选择预设配色，复用主启动图标的 Activity alias 切换。新增配色接入正常启动页、关闭启动页图标的入口、设置预览和通知单色图标；所有 alias 均由既有启用单个入口的策略管理。
- 不创建自定义配色快捷方式，不保存任意颜色偏好。主启动图标与预览使用打包的相同矢量资源。

### BiliPai 矢量图标比例与填充

Android 的所有 `ic_bilipai_mark*.xml` 与动态色启动页前景直接使用原始 1254 坐标轮廓，不额外缩放。主启动图标、设置预览与启动页共用原图比例。桌面遮罩沿用系统行为，字形镂空由路径填充规则保留。

SVG 路径采用 `fill-rule="evenodd"`，Android 必须保留对应的 `android:fillType="evenOdd"`，否则 b、P、a 的内部镂空会被填实。路径更新后执行 `python3 artwork/app-icon/sync_bilipai_vector_paths.py`，同步全部配色、单色层和动态色启动页前景；脚本同时传递路径与填充规则，保留各资源的颜色、着色和安全区参数。字形对照必须从 Android XML 中读取路径与填充规则进行渲染，不能只验证原始 SVG。

### 跟随应用主题色

图标页的「BiliPai 主题色」默认使用最终主色端点，支持系统壁纸、系统壁纸重新调色、自定义种子色与高级主色覆盖；开启独立调色时使用单独保存的标志颜色。自动背景模式保留每个 RGB 通道六级、共 216 档匹配，逐通道误差最多 25。独立背景使用 42 种标志色与 12 种背景色的 504 种组合，共打包 720 档图标。色板源数据位于 `bilipai-icon-color-palette.json`。自动背景下浅色标志使用墨色背景，其余使用白色背景。该选项不调用系统主题色接口改写用户壁纸或系统设置。

执行 `python3 artwork/app-icon/export_theme_icon_palette.py` 可从 `bilipai-mark.svg` 重新导出矢量、adaptive-icon、启动主题、启动入口类与 Manifest 色板区块。每个色板保留正常启动和关闭启动图标的 alias，图标设置只显示一个主题色选项。入口启停与已有图标选择共用串行同步；Android 13 起批量提交启停状态，旧版本先启用目标再关闭当前入口。

只有主窗口将最终色板同步到桌面。取色弹窗与其他主题预览不写桌面状态，主题颜色动画帧不参与匹配；预览图标使用同一端点索引。图标选择和匹配档位分别保存，启动时恢复上次档位，主题就绪后再同步最新结果。

### 实时调色预览

应用图标页提供「调色与预览」编辑器。草稿保存在本地 Compose 可恢复状态，拖动取色控件只更新预览，取消不保存；点击「应用到主图标」后保存图标独立颜色或恢复跟随应用主题色，并选择对应的主启动图标。独立配色不会修改应用主题种子或主题颜色来源。

所选颜色与桌面匹配色并排展示，均由 `AdaptiveIconDrawable` 绘制相同轮廓、填充规则和系统遮罩。桌面匹配色与实际色板共用配色组合索引和背景规则；匹配之前和之后的色值分别显示。独立标志色与背景色作为同一份设置在 DataStore 中保存，并缓存至 `app_icon_cache`；普通图标切换不删除独立颜色。

调色编辑器直接复用主题取色的 `ThemeColorSelectionControls`：包含二维饱和度/亮度选色、色相条、HEX 输入及常用颜色的展开/收起。切换调色对象可分别编辑标志和背景；背景可恢复自动搭配。选色只更新草稿和预览，保存时匹配完整的前景/背景组合；连续取色不改变桌面预置色板的匹配范围。跟随应用主题色时仍可单独设置背景。无效 HEX 不能应用，离开当前调色对象时放弃尚未构成有效颜色的文字，保留最后一个有效颜色。
