# 按需矢量图标

`:material-icons` 保存项目使用的扩展矢量定义，手机端、TV 和设计系统共用。
图标路径、尺寸、自动镜像属性与延迟缓存均保持源文件原样。基础图标及构造 API
继续由 `material-icons-core:1.7.8` 提供，不在本地重复定义。

新增图标时，从同版本源归档补入对应文件，或在 Gradle 缓存已有源码归档的环境执行：

```sh
python3 scripts/sync_curated_icons.py
```

脚本只读取本地源码归档并刷新子集，不运行 Gradle，不下载依赖。
它扫描各模块源码的显式导入、完整路径、`Icons` 接收者访问与自动镜像别名依赖；
通配符导入通过实际接收者访问筛选。新增图标时应使用显式导入或完整接收者访问。
`sources.json` 记录归档坐标、SHA-256 和每个保留文件的 SHA-256，便于核对来源。
