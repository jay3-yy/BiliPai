# 设备接力

客户端在局域网内直接交换普通视频（BV / 分 P CID / 进度 / 倍速 / 画质、音轨与弹幕偏好 / 纯听模式标记 / 分 P 与合集播单上下文）、番剧（Season / EP / 进度 / 倍速 / 画质、音轨与弹幕偏好 / 播单上下文）和直播（房间号 / 主播 / 画质与弹幕偏好）的播放元数据，不传输视频文件、Cookie 或登录令牌。两端分别使用自己的登录状态和播放权限。

## 使用流程

1. 两端连接可互通的局域网，打开「设置 → 播放器与画质 → 跨设备播放 → 设备接力」，开启设备接力。可在顶栏点击本机名称徽标自定义昵称（如「客厅平板」），自定义名称会随 NSD 与已连接会话实时同步给对端。
2. 点击发现的附近设备，或在「二维码 / 配对码配对」中生成二维码并由另一台设备「扫码配对」，逐组核对两端显示的 8 组身份校验码并在两端分别允许。配对成功后，两端在同局域网打开 BiliPai 时会自动静默重连。
3. **主动推送（推）**：在播放器顶栏（竖屏/横屏/液态玻璃均紧邻投屏/听视频入口，已连接可信设备时附带在线圆点）、视频详情页「简介 / 评论」标签栏右侧（仅在开启设备接力时智能显现）、竖屏全屏、横屏播放器「更多 → 设备接力」、纯听模式「更多 → 设备接力」或直播间「更多 → 设备接力」点击入口。若当前仅连接唯一受信任设备且正在播放内容（含后台独立进程听视频），会直接进入全屏中央大视频卡片流转舞台（顶部胶囊可一键切回设备管理列表）；上滑卡片、快速上甩或点击「立即接力」即可飞出发送。
4. **对称接收与自动接续**：收到推送时，接收端默认展示对称的上方下落大视频卡片舞台；普通视频可在舞台上自由切换「画面续播」与「继续纯听」（默认跟随对端模式，支持听转看、看转听与听转听）；若在面板中开启「受信任设备自动接续」，则播放下落过场后自动打开并恢复进度与播单上下文。
5. **无感拉取（拉）**：已连接信任设备正在播放内容时，仅通过加密长连接同步轻量当前播放状态（不包含播单列表，也不放入明文局域网广播）；另一台设备打开 BiliPai 后会在顶部浮现「接力续播」浮条（或在设备面板的对应设备卡片中显示），一键点击即可拉取续播。
6. 接收端打开目标内容前会按传输附带的队列窗口（最多 24 条）还原分 P / 合集 / 外部播单与循环模式，待就绪后向发送端获取最新毫秒进度（直播等待出流确认），恢复倍速并开始实际播放；发送端收到实际播放确认后才会自动暂停。准备期间发送端切换内容、进度、倍速或播放状态会中止交接。
7. **双向弹幕、画质、倍速与音轨（杜比 / Hi-Res / 多语言）偏好提示**：发送舞台、接收舞台、顶部远端浮条与设备卡片均会实时展示对端当前画质、杜比/Hi-Res 音质、多语言音轨、倍速与弹幕开关状态；接收确认舞台检测到弹幕开关不同时可直接勾选「接续时同步弹幕」，接续完成后若本机实际画质、音质/音轨或弹幕与对端仍有差异，会弹出非阻塞顶部偏好提示条（同时确认已同步的倍速），支持一键同步弹幕或在当前内容支持对应档位时一键切换画质、杜比/Hi-Res 音质或多语言音轨。

设备身份持久保存。监听和连接只在接力开启且应用前台可见时保持（含 Activity 切换短暂宽限期）；退到后台后自动关闭连接，后台不会唤醒或自动播放。关闭接力或解除配对会立即关闭相应连接。

## 手机与模拟器

模拟器可能收不到局域网发现广播。此时在手机生成五分钟有效的配对码，复制到模拟器的「无法自动发现？使用配对码手动配对」，由模拟器发起连接，再在两端核对身份。配对码须完整复制，包括地址、公钥指纹和一次性令牌。

连接保持期间，两个方向（推与拉）都复用这条连接，不要求手机反向连接模拟器默认地址。断线或应用退到后台后，该连接会关闭；如果手机不能访问模拟器地址，在模拟器端点击已配对手机旁的「连接」，恢复双向连接即可。

## 协议与信任

- NSD 服务 `_bilipai._tcp.`，TCP 端口 39327；广播只提供候选地址、设备名与形态（手机/平板/电视），不广播观看内容，也不直接建立信任。
- TLS 1.2/1.3 双向证书认证，私钥保存在 Android Keystore，不导出。首次配对仅在面板打开或配对码有效期内接纳候选身份；未建立信任前只允许身份确认。
- 两端展示由双方公钥指纹排序后计算的 128 位身份摘要，需逐组比对一致。双方确认后通过提交消息保存信任；后续操作必须匹配已信任证书公钥。
- 单条 TLS 流承载双向请求和回执（`hello`、`presence`、`video`、`pull`、`snapshot`、`pull_commit`），按请求编号关联；视频与番剧交接使用独立编号并二次同步最新进度。
- 消息协议版本为 3，支持普通视频、番剧、直播及 Presence / Pull 双向联动。手动配对码沿用 `bilipai-pair://v1` 地址格式（可选携带 `type` 设备形态参数）。
- 信任记录不参与云备份和设备迁移。解除配对删除本机记录并断开连接；不向对端远程删除其本地记录。
- 仅传递元数据，封面域名、播放参数和地址均受限。配对认证设备身份，不认证对端 APK 的发行身份。

## 动画与界面

保留 320 毫秒卡片飞出、飞入和失败回落，动态封面模糊及不超过 1.8dp 的边缘起伏。顶部无感接力浮条使用一次性入场/退场动画，无无限循环动画；减弱动效关闭运动与模糊。面板与浮条使用应用 `design-system` 门面组件与 `AppPopupSurface`，同步适配 MD3、Miuix 与液态玻璃及手机/平板/窄分屏。
