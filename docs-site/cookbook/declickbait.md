# 食谱 1：去标题党与热点刷屏折叠（`feed.pipe`）

- **交付形态**：`.bpx.json`（纯声明式规则，走 Kotlin 原生零分配快路径，0 虚拟机开销）
- **原位挂载**：首页推荐、热门与搜索卡片流
- **一键实操**：[⚡ 在校验扫码台打开此食谱](/playground?recipe=declickbait)

## 设计亮点

旧版过滤规则只能粗暴地把整张卡片 `hide`（隐藏），导致遇到标题夸张但内容尚可的视频容易误伤。`.bpx` v1 的 `feed.pipe` 引入了三种温和而优雅的动作：

1. **`rewriteTitle`（原地净化标题）**：匹配并剥离标题开头的 `震惊！`、`家人们谁懂啊` 等情绪前缀，保留正文干货。
2. **`fold`（同类温和折叠）**：将时长过短且低赞的引流卡片合并为单行可展开胶囊，想看仍可点开。
3. **`badge`（三材质光学角标）**：为 30 分钟以上的长视频在封面右上角渲染一枚自适应毛玻璃角标「深度长片」。

## 二次改造灵感（可直接发给 AI）

- 为科技区含「恰饭」「商单」关键词或简介带淘宝口令的卡片打上 `warning` 色调的「含商业推广」角标；
- 在深夜 23:00 后折叠美食探店类卡片（结合 `scene.hour` 条件）。
