# 食谱 5：评论区「指路课代表」置顶卡（`community.craft`）

- **交付形态**：`.bpx.js`（纯本地热评扫描）
- **原位挂载**：视频评论区顶栏速览位 & 刷屏折叠层
- **一键实操**：[⚡ 在校验扫码台打开此食谱](/playground?recipe=comment-rep)

## 设计亮点

很多长视频的精华时间轴藏在第 3～10 条热评里，同时前排常被「拉低中奖率」「转发抽奖」占满：
1. **指路热评秒变章节条**：正则提取 `mm:ss 节点说明` 后返回 `pinnedCard.timestamps`，宿主直接在评论区顶端渲染一张紧凑的可点击跳转卡片。
2. **温和折叠水评**：将命中抽奖模板的评论 `rpid` 放入 `foldRpids`，宿主将其收拢为可展开的次级折叠条，不破坏楼层连续性。
