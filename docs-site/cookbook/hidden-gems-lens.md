# 食谱 4：「冷门宝藏」推荐流透镜（`home.lens`）

- **交付形态**：`.bpx.js`（纯本地重排计算，0 外部网络请求）
- **原位挂载**：首页顶栏透镜切换器
- **一键实操**：[⚡ 在校验扫码台打开此食谱](/playground?recipe=hidden-gems-lens)

## 设计亮点

把推荐流排序权交还给用户自己：
1. **纯本地隐私安全**：仅声明 `videoContext: ["candidates", "historySummary"]`，不申请任何 `networkDomains` 联网权限，安装核验单直接显示绿色「🔒 纯本地运行」徽章。
2. **可解释推荐理由**：每条重排结果可附带 `reasonBadge`（如 `高赞播比宝藏`），宿主会在视频卡片下方以次级语义色温和呈现推荐依据。

## 二次改造灵感（可直接发给 AI）

- **「下饭专线透镜」**：只保留 8～22 分钟的美食、人文、纪录片分区视频；
- **「深度学习透镜」**：屏蔽娱乐热搜分区，按收藏/播放比排序知识与科技区长视频。
